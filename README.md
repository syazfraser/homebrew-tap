# syazfraser's Homebrew tap

Apps by [syazfraser](https://github.com/syazfraser), installable with [Homebrew](https://brew.sh).

| App | Install | What it does |
| --- | --- | --- |
| [SGBusBar](https://github.com/syazfraser/SGBusBar) | `brew install --cask syazfraser/tap/sgbusbar` | Singapore bus arrivals in your Mac's menu bar |

Or add the tap once and use the short name from then on:

```bash
brew tap syazfraser/tap
brew install --cask sgbusbar
```

Update with `brew upgrade --cask sgbusbar`. The casks here are updated automatically when a new version is released.

SGBusBar isn't notarised by Apple yet, so the first time you open it, macOS may block it: open
**System Settings > Privacy & Security** and click **Open Anyway**.
